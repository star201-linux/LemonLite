LemonLite 示例小程序

这个页面的全部颜色都来自 var(--md-*)，会跟着宿主主题一起变。

基础能力

网络请求（由宿主发起，无跨域限制）

本地存储（宿主 SharedPreferences，按小程序隔离）

自定义主题（覆盖 CSS 变量）

打开后本页把 --md-primary 等变量改成自定义值。 这就是「小程序自定义主题」的官方姿势：覆盖同名变量，框架不干预。

设备：音量与亮度

由宿主原生通道执行（音量走 AudioManager，亮度只改本 App 的窗口亮度、不动系统设置）。 两者都受「设置 → 应用 → 权限控制器」管辖。

页面标记：屏幕方向 / 允许熄屏

方向由写页面的人标记（类似安卓里调 SDK）。标记跟着会话走： 小程序退到后台会自动恢复「自动」，不会让宿主其它页面也被锁住。

文件（每个小程序独立目录）

所有 path 都相对这个目录，`..` 与绝对路径会被宿主拒绝。

内置 WebAssembly

模块随 APK 打包（assets/wasm/lemonlite.wasm），离线可用，不引任何 CDN。 同一个模块只会编译一次，之后重复 instantiate 走的都是缓存。
