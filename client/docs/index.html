LemonLite 示例小程序资源

这个目录放的是示例小程序的静态文件，不是应用市场的数据源。

⚠ 市场数据不再来自这里

从 0.5 起，宿主 App 只从 LemonLite 服务端读取市场数据 （GET /api/market/feed 与 /api/market/search）， 不再拉取 index.json。 服务端代码在仓库的 server/ 目录，部署方式见那里的 README。

在本目录放静态文件仍然有用：它可以直接当小程序页面的托管地址， 也可以作为服务端 apps.url 指向的目标。

这里有什么

  1. demo/index.html —— 示例小程序（演示全部 JSBridge API 与主题继承）
  2. apps/ —— 示例小程序（记事 / 天气 / 番茄钟 / Markdown / 二维码 / 配色 / 2048）
  3. icons/ —— 上面这些应用的图标
  4. screenshots/ —— 详情页用的竖版预览图

模块与扩展示例包

页面扩展可在普通设置 →「页面扩展」导入，不需要开发者模式；模块仍在开发者选项 →「模块」里安装。

  1. bundles/demo-extension.zip —— 扩展示例：给页面加调试边框与角标（会跟随主题）
  2. bundles/demo-module.zip —— 模块示例：声明 lemonlite.greet() 等新 API
  3. bundles/src/ —— 上面两个包的源码目录，可以照着写自己的

怎么把示例挂到自己的服务端上

  1. 把这个目录发布成一个静态站点（GitHub Pages / 对象存储都行）
  2. 在服务端数据库的 apps 表里，把 url 指向它的地址， 例如 https://your-site/apps/todo/index.html
  3. 或者直接跑 cd server && npm run init -- --seed， 预置的演示数据已经指向 https://star201-linux.github.io

图标与介绍图也会被服务端当作 URL 返回，所以同样可以是绝对地址。 页面里写 var(--md-surface) 之类的 CSS 变量就会自动跟随宿主主题。
