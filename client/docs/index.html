LemonLite 示例资源

这里只剩「页面扩展 / 模块」的示例包；小程序示例已经全部移除。

⚠ 不再内置任何示例小程序

从 0.7 起，市场默认是空的：没有任何预置小程序。 应用由管理员在服务端 /admin 面板里新建、上传 zip 与图标后才会出现。 仓库里也不再保留示例小程序的源码与包。

自己写一个小程序：新建一个 zip，根目录放 index.html （可用 var(--md-surface) 等变量跟随宿主主题）， 在面板「应用」页上传即可。

模块与扩展示例包

页面扩展可在普通设置 →「页面扩展」导入，不需要开发者模式；模块仍在开发者选项 →「模块」里安装。

  1. bundles/demo-extension.zip —— 扩展示例：给页面加调试边框与角标（会跟随主题）
  2. bundles/demo-module.zip —— 模块示例：声明 lemonlite.greet() 等新 API
  3. bundles/src/ —— 上面两个包的源码目录，可以照着写自己的
