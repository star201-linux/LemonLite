# 轻柠小程序开发文档

面向要写小程序的人。宿主（轻柠 App）的架构不在这里展开，只看「怎么做一个能装进去、能跑、能上架」的小程序。

---

## 1. 五分钟做一个

最小的可用包只有两个文件：

```
hello/
├── metadata.json
└── index.html
```

`metadata.json`：

```json
{
  "id": "com.example.hello",
  "name": "你好",
  "version": "1.0.0",
  "entry": "index.html",
  "description": "最小示例",
  "author": "you",
  "permissions": []
}
```

`index.html`：

```html
<!DOCTYPE html>
<html>
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>你好</title>
</head>
<body>
  <h1>你好，轻柠</h1>
  <button onclick="sayHi()">打个招呼</button>
  <script>
    async function sayHi() {
      const info = await lemonlite.getSystemInfo();
      await lemonlite.showToast('运行在 ' + info.platform + ' 上');
    }
  </script>
</body>
</html>
```

打包（`metadata.json` 必须在 zip 根目录；外面再套一层目录也可以，宿主会自动剥掉）：

```bash
cd hello && zip -r ../hello.zip . -x '.*'
```

装进设备的方式见第 9 节。**不需要写一行原生代码。**

---

## 2. 包结构

```
my-app/
├── metadata.json       # 必需：身份、版本、入口、声明权限
├── index.html          # 入口页（可用 metadata.entry 改名）
├── app.js              # 你的脚本
├── style.css           # 你的样式（可选）
└── assets/             # 图片、字体…（可选）
```

规则：

- zip 内路径会被校验，**不允许** `../`、绝对路径、盘符。
- 单包上限：压缩包 20 MB，解压后 80 MB，最多 2000 个文件。
- 入口文件必须存在，否则安装直接失败（不会留一个打不开的包）。
- 小程序运行在虚拟源 `https://miniapp.lemonlite.local/<appId>/<version>/` 下：
  有真实的 origin，相对路径、`<script type="module">`、`fetch` 都按普通网页工作。
  想拆文件就直接拆：`<script type="module" src="app.js">` + `import './icons.js'`
  可以正常加载 —— 这些请求由宿主从解压目录直接响应，不经过网络。
  这个域名不会联网 —— 宿主直接从解压目录喂内容。

---

## 3. `metadata.json`

这是小程序自己的「AndroidManifest」。宿主以它为准，不看市场数据里的同名信息。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | ✅ | 全局唯一。小写字母 / 数字 / `.` `_` `-`，最长 64。**必须与服务端分配的 appId 一致**，不一致直接拒绝安装 |
| `name` | ✅ | 展示名（应用管理、最近任务、权限页都用它） |
| `version` | ✅ | 版本号，建议语义化（`1.2.0`）。更新检查以服务端上架版本为准，这里用于本机记录与展示 |
| `entry` | | 入口文件，默认 `index.html` |
| `description` | | 简介 |
| `author` | | 作者 |
| `icon` | | 包内图标相对路径（可选；市场图标优先） |
| `permissions` | | 声明申请的权限 id，见第 4 节 |
| `minFrameworkVersion` | | 要求的最低宿主版本。高于当前宿主时**拒绝安装**，而不是让页面白屏 |

安装时的校验顺序：`id` 一致 → 框架版本够 → 入口文件存在。任何一步失败都会丢弃整个包，不会留下半成品。

> 老包可以没有 `metadata.json`（按服务端信息安装），但那样权限页只能显示「运行时请求过的」，
> 用户也看不到你要什么。新包请务必带上。

## 4. 权限

权限分两类，机制不同：一类是**浏览器自己的受控资源**（页面用标准 Web API 请求，
宿主在 WebView 层拦下来），一类是**Android WebView 没有实现的标准 API**
（只能走 JSBridge，宿主在桥接层拦）。

无论哪一类，默认状态都是「询问」：第一次调用一定弹窗，宿主不会替用户做主。

### 4.1 浏览器受控资源

页面写标准 API 就行，不需要认识 `lemonlite`：

```js
// 摄像头 / 麦克风
const stream = await navigator.mediaDevices.getUserMedia({ video: true, audio: true });

// 定位
navigator.geolocation.getCurrentPosition(
  (pos) => console.log(pos.coords.latitude, pos.coords.longitude),
  (err) => console.warn(err.code), // 1 = PERMISSION_DENIED
  { enableHighAccuracy: false },
);

// 剪贴板
await navigator.clipboard.writeText('hello');
```

被拒绝时页面拿到的是 Chromium 自己的 `DOMException`（`NotAllowedError`）或
`GeolocationPositionError`（`code: 1`），照常 `try/catch` 即可。

| 能力 | 页面侧入口 |
| --- | --- |
| 摄像头 / 麦克风 | `getUserMedia({video|audio})` |
| 屏幕捕获 | `getDisplayMedia()` |
| 音频输出设备 | `HTMLMediaElement.setSinkId()` |
| 画中画 | `video.requestPictureInPicture()` |
| 位置 | `navigator.geolocation.*` |
| 运动 / 方位传感器 | `new Accelerometer()`、`new Gyroscope()`、`new Magnetometer()`、`devicemotion` |
| 环境光 / 距离感应 | `new AmbientLightSensor()`、`new ProximitySensor()` |
| 游戏手柄 | `navigator.getGamepads()` |
| 振动 | `navigator.vibrate()` |
| MIDI | `navigator.requestMIDIAccess()` |
| 剪贴板 | `navigator.clipboard.*` |
| 通知 | `Notification.requestPermission()` |
| 文件 | `<input type="file">`、File System Access API |
| 电池 / 内存 / 网络 | `getBattery()`、`navigator.deviceMemory`、`navigator.connection` |
| 生物识别 | `navigator.credentials.create() / get()`（WebAuthn） |
| 打印 | `window.print()` |

### 4.2 定位：两个独立维度

定位**只有一项权限** `location`，但授权由两个正交维度组成，和 Android 一致：

| 维度 | 取值 | 含义 |
| --- | --- | --- |
| 时间 | 仅前台 / 允许后台 | 小程序切到后台后还能不能读位置 |
| 精度 | 精确 / 近似 | 近似约 3 平方公里，精确是米级 |

规则只有一条，但会被严格执行：**后台精度永远不超过前台**。只给了近似，
后台也只能拿到近似 —— 数据结构上就不存在「后台更准」这个状态。

用户在权限管理页（或第一次弹窗）里分别设置这两项，代码里不用也不能指定：

```js
// 你无法要求「必须精确」—— 那是用户的选择。
// 能做的只有：开启高精度提示，并把 accuracy 当作真实精度使用。
navigator.geolocation.watchPosition(
  (pos) => {
    const { latitude, longitude, accuracy } = pos.coords;
    // 近似位置时：accuracy >= 1500，且 altitude / speed / heading 为 null
    renderNearby(latitude, longitude, accuracy);
  },
  (err) => {},
  { enableHighAccuracy: true, maximumAge: 10000 },
);
```

近似位置由页面侧强制取整（0.02° 网格，约 2 km 一格），即使系统给了精确坐标，
页面拿到的也只会是取整后的值。切到后台且未授权后台定位时，`watchPosition`
的回调会收到 `code: 1` 并停止投递。

想提前知道当前策略，可以读只读快照：

```js
const policy = window.lemonliteGeoPolicy();
// { allowed: true, precision: 'coarse', background: false }
```

### 4.3 宿主转接的标准 API

Android WebView 没有实现 Web Bluetooth / Web NFC，这两项走 JSBridge，
语义与标准 API 对齐（设备发现 → 连接 → 读写）。**第一次调用会先弹应用内确认框**，
拒绝时 Promise 以 `{code: 40001}` reject。

```js
const { devices } = await lemonlite.bluetooth.scan({ durationMs: 5000 });
await lemonlite.bluetooth.connect(devices[0].address);

const tag = await lemonlite.nfc.read();
await lemonlite.nfc.writeText('https://example.com');
```

WebUSB / Web Serial 在 WebView 里通常不可用 —— 代码可以照标准 API 写，
但拿不到 `navigator.usb` / `navigator.serial` 时要有降级分支。

### 4.4 权限 id 一览

`metadata.json` 里写的 id 就是浏览器权限名（与 `navigator.permissions.query({name})`
同一套词汇）。不知道自己该写哪个，就写你实际调用的那个 API 对应的那行：

| id | 名称 | 分组 | 风险 | 底层 |
| --- | --- | --- | --- | --- |
| `camera` | 摄像头 | 媒体与显示 | 敏感 | Android `CAMERA` |
| `microphone` | 麦克风 | 媒体与显示 | 敏感 | Android `RECORD_AUDIO` |
| `displayCapture` | 屏幕捕获 | 媒体与显示 | 敏感 | 系统 MediaProjection 确认框 |
| `speakerSelection` | 音频输出设备 | 媒体与显示 | 常规 | 无 |
| `pictureInPicture` | 画中画 | 媒体与显示 | 常规 | 无 |
| `location` | 位置信息 | 位置 | 敏感 | `FINE` / `COARSE`，后台另加 `ACCESS_BACKGROUND_LOCATION` |
| `accelerometer` | 加速度计 | 传感器 | 常规 | 无 |
| `gyroscope` | 陀螺仪 | 传感器 | 常规 | 无 |
| `magnetometer` | 磁力计 | 传感器 | 常规 | 无 |
| `ambientLight` | 环境光 | 传感器 | 常规 | 无 |
| `proximity` | 距离感应 | 传感器 | 常规 | 无 |
| `gamepad` | 游戏手柄 | 输入与振动 | 常规 | 无 |
| `vibrate` | 振动 | 输入与振动 | 常规 | Android `VIBRATE`（安装期） |
| `midi` | MIDI 设备 | 输入与振动 | 敏感 | 无（WebView 拦截 SysEx） |
| `bluetooth` | 蓝牙 | 连接与近场 | 敏感 | `BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT` |
| `usb` | USB 设备 | 连接与近场 | 敏感 | 无 |
| `serial` | 串口设备 | 连接与近场 | 敏感 | 无 |
| `nfc` | NFC | 连接与近场 | 敏感 | 安装期权限，无运行时授权 |
| `networkInfo` | 网络信息 | 连接与近场 | 常规 | 无 |
| `webauthn` | 生物识别与安全密钥 | 身份与安全 | 敏感 | 无（系统验证框） |
| `clipboard` | 剪贴板 | 文件与剪贴板 | 敏感 | 无（WebView 拦截） |
| `sdcard` | 读取手机存储 | 文件与剪贴板 | 高风险 | 系统文件选择器（SAF） |
| `notifications` | 通知 | 系统与设备 | 常规 | Android 13+ `POST_NOTIFICATIONS` |
| `battery` | 电池状态 | 系统与设备 | 常规 | 无 |
| `deviceMemory` | 设备内存 | 系统与设备 | 常规 | 无 |
| `print` | 打印 | 系统与设备 | 常规 | 无 |

### 4.5 声明

```json
"permissions": ["camera", "microphone", "location", "vibrate"]
```

**声明只是「告知」，不是「预授权」**：用户的默认状态永远是「询问」。声明的作用是让权限页
在用户打开之前就能列出「它要什么」，而不是等第一次弹窗才让人反应过来。

声明漏写但运行时真的调用了，权限页会把它列出来并标「运行时请求」—— 能用，但用户会觉得
这个应用在偷着要东西。**该写的都写上。**

不需要授权的能力（音量、亮度、屏幕方向、常亮、文件沙箱、下载、Toast…）直接在 API 里用，
不要往 `permissions` 里塞。

## 5. JSBridge

全局对象 `window.lemonlite`。所有方法返回 Promise；失败时 reject 一个
`{code, message}` 对象（不是 `Error` 实例，别用 `instanceof` 判断）。

```js
try {
  await lemonlite.setStorage('k', { a: 1 });
} catch (e) {
  console.warn(e.code, e.message);   // 10001 / 20001 / 40001 …
}
```

### 5.1 基础

| 方法 | 说明 |
| --- | --- |
| `getSystemInfo()` | 平台、版本、屏幕、语言等 |
| `getTheme()` | 当前主题（`mode` / `seed` / 颜色变量） |
| `onThemeChange(cb)` | 订阅主题变化，返回取消订阅函数；订阅时立刻回调一次 |
| `setTitle(title)` | 改标题（影响最近任务卡片，走 300ms 去抖） |
| `showToast(message, {duration})` | 轻提示 |
| `navigateBack()` | 页面历史后退；退无可退时按宿主规则退出 |
| `openUrl(url)` | 交给系统浏览器 / 对应 App |
| `close()` | 关闭当前小程序 |

### 5.2 存储

`setStorage(key, value)` / `getStorage(key, default)` / `removeStorage(key)` /
`clearStorage()` / `getStorageKeys()`。值会 JSON 序列化，按 appId 隔离。

### 5.3 网络

`request({url, method, headers, body, timeout})` —— 走宿主原生 HTTP，不受页面 CSP 限制。

### 5.4 文件

两个作用域，都不需要授权：

| 作用域 | 位置 | 用途 |
| --- | --- | --- |
| `shared` | 外部存储 `Android/data/<包名>/files/appfiles/<appId>` | 用户可见、可导出 |
| `private` | 内部存储 `files/appfiles/<appId>` | 私有缓存 |

`getAppFileDir({scope})`、`readFile`、`writeFile`、`appendFile`、`listFiles`、
`deleteFile`、`mkdir`、`exists`、`fileInfo`。

```js
await lemonlite.writeFile('notes.json', JSON.stringify(notes), { scope: 'private' });
const r = await lemonlite.readFile('notes.json', { scope: 'private' });
// r = { path, scope, found, data, bytes }
```

路径一律是**相对沙箱根**的（`notes.json`、`img/a.png`），传绝对路径会被拒绝。
`getAppFileDir()` 返回的是绝对路径，只用于展示 / 排障。

### 5.5 设备

| 方法 | 说明 |
| --- | --- |
| `getVolume()` / `setVolume(0-100)` | 媒体音量 |
| `getBrightness()` / `setBrightness(0-1)` | 屏幕亮度 |
| `setPageOrientation('portrait'\|'landscape'\|'auto')` / `getPageOrientation()` | 页面方向 |
| `setKeepScreenOn(bool)` / `setAllowScreenOff(bool)` / `getKeepScreenOn()` | 常亮 |
| `runInBackground()` | 转入后台继续跑（JS 定时器会被挂起） |

### 5.6 蓝牙 / NFC

```js
await lemonlite.bluetooth.scan({ durationMs: 5000 });
lemonlite.bluetooth.onScanResult((device) => console.log(device));
await lemonlite.bluetooth.connect(deviceId);
await lemonlite.bluetooth.write(deviceId, serviceUuid, characteristicUuid, bytes);
lemonlite.bluetooth.onNotification((payload) => {});   // 返回取消订阅函数

await lemonlite.nfc.read();                        // 读 NDEF
await lemonlite.nfc.writeText('hello');            // 写一条 Text 记录
```

二进制参数用 `Uint8Array`，桥接层自动做 base64。

### 5.7 下载

`lemonlite.download.save({url, fileName})` 交给系统下载器，落盘在 `Download/`；
`lemonlite.download.list()` 查看记录。下载进度由系统通知栏展示，页面不需要轮询。

### 5.8 插件

`lemonlite.plugins.list()` 返回这台设备上的插件（含停用 / 平台不匹配的）；
`lemonlite.plugins.has('能力名')` 判断某项能力是否可用。当前宿主还没有内置
能力实现，这一组主要用于展示与探测。

### 5.9 错误码

| code | 含义 |
| --- | --- |
| `0` | 成功 |
| `10001` | 参数错误 |
| `10002` | 桥未就绪 |
| `10003` | 不支持的能力 |
| `20001` / `20002` / `20003` | 网络错误 / 超时 / HTTP 状态异常 |
| `30001` | 存储错误 |
| `40001` | 权限被拒绝（去权限管理里打开） |
| `50001` | 设备能力不可用（蓝牙关闭、没有 NFC 硬件） |

## 6. 样式：不用写 CSS 也是 MD3

宿主在**页面解析之前**就把 MD3E 样式写进 `<head>`，所以你什么都不写也不会是
「浏览器默认样式」：按钮是胶囊、输入框有圆角描边、表格有分隔线、链接是主题色。

主题色来自宿主的 `--md-*` 变量，深浅色和动态取色自动跟随：

```css
.my-card {
  background: var(--md-surface-container);
  color: var(--md-on-surface);
  border-radius: 20px;
  padding: 16px;
}
```

可用的变量：`--md-primary` `--md-on-primary` `--md-primary-container`
`--md-on-primary-container` `--md-surface` `--md-on-surface`
`--md-surface-container(-high/-highest)` `--md-on-surface-variant`
`--md-outline` `--md-outline-variant` `--md-secondary-container`
`--md-on-secondary-container` `--md-tertiary-container` `--md-error` …

接管规则：

- 只接管「作者没管过」的原生控件（没有 `id`、`class`、外观相关的内联 `style`、`role`）。
- 你一旦补上 class 或外观 style，宿主立刻撤标记 —— **永远不会抢你的样式**。
- 想整块放过（例如嵌入代码编辑器），给容器加 `data-md3e="off"`。
- 运行时开关：`lemonlite.md3e.disable()` / `enable()` / `apply(el)` / `refresh()`。

## 7. 运行环境

- 页面跑在虚拟源 `https://miniapp.lemonlite.local/<appId>/<version>/` 下，是正常的
  secure context：module script、动态 `import()`、`localStorage`、Worker 都可用。
  这个域名不会真的联网，但**也不要写死** `location.origin`，用相对路径。
- 跨站 `fetch` 仍受 CORS 约束（对方不给 `Access-Control-Allow-Origin` 就是不行）。
  调接口请用 `lemonlite.request`：它走宿主原生请求，没有 CORS，也带不上 Cookie。
- 一个页面 = 一个小程序窗口；`localStorage` 可用，但**长期数据请用 `setStorage`**
  （按 appId 隔离，清缓存时不会误删别人的）。
- 系统返回键：先走页面历史；历史到头再按一次，按宿主当前模式退出
  （独立窗口 = 关闭这张任务卡）。
- 从后台切回来时 JS 定时器会恢复；后台期间是挂起的，不要依赖「后台也在跑」。

| 位置 | 显示 |
| --- | --- |

## 9. 调试

1. 设置页连点版本号 8 次解锁开发者选项；
2. 开发者选项 → **小程序测试** → 选一个本地 **ZIP 包**，点「导入并打开」；
   包会解压到应用私有目录（`miniapps/<appId>/dev-<时间戳>/`），入口默认 `index.html`，
   有 `metadata.json` 时以它的 `id` / `entry` 为准；
3. 也可以在开发者选项里把市场服务器指向本机，走「上架 → 客户端打开」的完整流程。

> 调试包用 `dev-<时间戳>` 做版本号，**同一个包再次导入会覆盖上一次**，
> 不会在磁盘上堆十个版本。没有 `metadata.json` 时 appId 由文件名生成（带
> `dev.local.` 前缀），不会和市场上正式应用的数据混在一起。

常用排查：

```js
console.log(await lemonlite.getSystemInfo());
console.log(await lemonlite.getTheme());
```

页面里的 `console` 会进宿主日志（开发者选项 → 运行日志）。

## 10. 上架与更新

1. 服务端 `/admin` 新建应用，填 appId（必须与 `metadata.json` 的 `id` 一致）；
2. 上传 zip，填版本号与入口（入口会被包里的 `entry` 覆盖）；
3. 客户端启动时批量查更新，打开前再查一次单个；
4. 有新版本：应用管理出现小红点，详情页按钮变成「更新 / 打开」两个。

服务端会记录 SHA-256，客户端下载后校验；校验不过直接丢弃。**版本号变了就算新版本**
（不比较大小），回滚时把版本号改回去并重新上传即可。

## 11. 常见问题

**Q：安装时报 `metadata_mismatch`？**
`metadata.json` 的 `id` 和管理员填的 appId 不一致。改一个，让它们相同。

**Q：安装时报 `framework_too_old`？**
`minFrameworkVersion` 写高了。要么降下来，要么让用户升级宿主。

**Q：样式被宿主改了？**
给元素补一个 class，或给容器加 `data-md3e="off"`。宿主只接管「没人管」的控件。

**Q：摄像头点了允许还是打不开？**
应用内授权只是第一层，Android 系统还有一层。去权限管理里点「打开系统设置授权」。

**Q：更新后页面没变？**
更新会关闭正在运行的旧会话；重新打开即可。若仍不变，检查服务端版本号是否真的变了
（版本号相同不会触发更新）。

**Q：能加载远程脚本吗？**
不推荐。小程序应当是「装好的东西」—— 远程脚本绕过 SHA-256 校验，也会让离线不可用。
需要动态数据请用 `lemonlite.request` 只取 JSON。
